# Pipelines artwork

`kubeflow-pipelines.svg` is the unmodified color icon from the [official CNCF artwork repository](https://github.com/cncf/artwork/blob/main/projects/kubeflow-pipelines/icon/color/kubeflow-pipelines-icon-color.svg). It is shared by the sidebar and browser favicon. Logo use follows the [CNCF artwork trademark policy](https://github.com/cncf/artwork/blob/main/LICENSE.md).

The graph canvas omits the optional React Flow watermark via its documented `hideAttribution` option. React Flow's MIT copyright and license are retained in `public/third-party/react-flow-LICENSE.txt` and shipped with the frontend assets.
